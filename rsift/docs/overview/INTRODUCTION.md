# Rsift / RsGraphics — 製品紹介 (Overview)

**対象読者: 一般 (製品を知りたい方) / 制定: 2026-07-24**

---

## 1. Rsift とは

**Rsift (アールシフト)** は、Minecraft (対象バージョン 1.21.11) のための、
**ネイティブ注入型 Rust 製 Mod Loader** です。従来の Java 製ローダー
(Fabric / Forge / NeoForge) が JVM 内で動くのに対し、Rsift はゲームの外側から
高性能ネイティブ言語でゲームを支える設計を取り、**読み込みの速さ・
動作の軽さ・描画の滑らかさ**を追求しています。

## 2. 4 つの柱

Rsift は関心の分離を徹底し、役割ごとの製品群で構成されます。

| 柱 | 役割 |
| :--- | :--- |
| **Rsift Loader** | Mod の読み込みとゲーム起動の統括。各種 API 互換層の提供 |
| **RsGraphics** | 描画エンジン。最新の GPU 活用技術で描画負荷の軽減を目指す |
| **RsCalc** | 計算処理のネイティブ化。ゲームロジック関連の高速化を担う |
| **RsReplay** | リプレイ機能の担い手 (優先度は Loader / RsGraphics が先行) |

## 3. プレイヤーにとっての価値

- **かんたん導入**: セットアップ実行ファイルによるワンクリック導入。
  ターミナル操作やコンパイルは不要です (詳しくは `docs/user/`)。
- **一目で分かる動作表示**: 読み込み成功が画面表示ですぐ確認できます。
- **軽量設計**: 低スペック PC でも恩恵が受けられるよう、
  要求ハードウェアを限定する技術に依存しない方針で設計しています。

## 4. Mod 開発者にとっての価値

- **ネイティブ DLL Mod**: Rust で書いた動的ライブラリを Mod として読み込めます。
- **充実した API ブリッジ**: Fabric / NeoForge 系の概念に対応する API を提供する
  ことを目標としています。
- 開発方法は **`docs/modding/MOD_DEVELOPER_API_GUIDE.md`** をご覧ください。

## 5. 互換性の目標

- Fabric API / NeoForge 系エコシステムの概念との**高い互換性**を目指して
  継続開発中です。
- シェーダー関連の互換性も視野に入れています。
- **性能目標**: 代表的な最適化 Mod 水準以上を設計目標としていますが、
  定量的な主張は検証済みのものに限定しています (検証文化は開発者向け
  ドキュメントに集約)。

## 6. 品質への取り組み (概要のみ)

Rsift プロジェクトでは、すべての性能・機能主張を**実測に基づく検証**で
管理しています。ベンチマークは追試可能な手順として整備されており、
文書の主張は監査で定期的に照合されます。これらの証跡は開発者向け資料
として管理しており、本紹介では詳細を割愛します。
