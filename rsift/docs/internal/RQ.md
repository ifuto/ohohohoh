# RQ 言語仕様書 v2 (rspeed 内蔵・AI 記述最優先の静的型付き小言語)

導入: 2026-07-26 (v1)。改訂: 2026-07-26 (v2)。
実装: `tools/rspeed.rs` 内の `rq_*` 系 (`rspeed rq` サブコマンド)。
目的: 監査で繰り返し使ってきた **Python (struct + ctypes libm) による f32 IEEE
エミュレート計算を rspeed に全面移行**するための実行基盤。

設計方針: **AI が生成ミスしにくいことだけを最優先**する。人間の読みやすさ・
見た目の美しさは追求しない。構文は極小・明示的・曖昧さゼロを貫く。

v2 追加の要約: `const` (§4.1)・複合代入 `+=` 等 (§4.2)・`for` 範囲ループ (§4.3)・
`break`/`continue` (§4.4)・`loop` (§4.5)・`match` 文 (§4.6)・固定長配列
`[T; N]` (§3)・配列組込 `len/fill/copy` (§6)・prelude 4 関数追加 (§7)。

v2.1 追加 (監査直結の拡張): 整数ビット演算 `& | ^ ~ << >>` (§5)・`elif` (§4)・
assert ラベル第 2 引数 (§4)・組込 `pi()/e()/tan()/hypot()/fma()` (§6)・
先頭ドット小数 `.5` の字句対応 (v1 は仕様書のみの記載で実装未対応だった欠落を根治)。

---

## 1. 呼び出し

```sh
rspeed rq <file.rq>                 # ファイル実行
rspeed rq -e 'let x: f32 = 0.1; p x;'   # インライン実行
rspeed rq --check <file.rq>         # 型検査のみ (実行しない)
rspeed rq --prelude -e 'p luma601(1.0, 0.0, 0.0);'  # 標準小関数群を前置
```

終了コード: `0` 成功 / `2` 構文・型エラー / `3` 実行時エラー (assert 失敗・
ゼロ除算・ステップ上限・深度上限・ret 抜け・配列境界外アクセス)。

エラー形式: `rq: 行 N: メッセージ` (stderr)。行番号は 1 始まり。
`--prelude` 使用時は prelude 9 行分だけ行番号がずれる。

## 2. 字句

- コメント: `#` から行末まで。
- 空白・タブ・改行は意味を持たない (区切りは全て記号)。
- 識別子: `[A-Za-z_][A-Za-z0-9_]*`。
- 予約語 (識別子に使用不可):
  `let const fn if elif else while for in loop match ret break continue p assert true false f32 i64 u32 bool str _`。
  `_` は match のワイルドカード専用。
- 文字列: `"..."`、エスケープは `\n` `\t` `\\` `\"` のみ (p/assert の引数専用)。
- 範囲演算子: `..` (排他終端) `..=` (包含終端)。`for` 専用。
- 小数リテラルと範囲の曖昧さ回避: `1..2` は整数 1 + `..` + 整数 2。
  `1.5`・`2.`・`.5` は小数 (ピリオド直後がもう一つの `.` でない限り小数点)。

## 3. 型 (6 種・暗黙変換なし)

| 型 | 内容 | リテラル |
|----|------|----------|
| `f32` | IEEE-754 単精度 (ハードウェア丸め) | `0.1` `1e-8` `2.` `.5` `1_000.5` |
| `i64` | 64bit 符号付き (算術は wrapping) | `123` `1_000` (`.`/`e` を含まない 10 進) |
| `u32` | 32bit 符号なし (算術は wrapping) | `0x3F800000` (16 進のみ・`_` 可) |
| `bool` | 真理値 | `true` `false` |
| `str` | 文字列 (p/assert 専用・演算不可) | `"..."` |
| `[T; N]` | 固定長配列。T ∈ {f32,i64,u32,bool}、N は 1..=256 の整数リテラル | `[1.0, 2.0, 3.0]` |

### 配列型の規則

- `[T; N]` はスカラーと同格の値型 (コピーセマンティクス)。代入・引数渡しで全要素コピー。
- 関数の引数・戻り値に使用可。配列の配列 `[[T;N];M]` は**禁止** (平坦のみ)。
- 要素型は全て同型。`[1.0, 0, false]` は型エラー。
- リテラルの要素数と宣言 `N` が一致しなければ型エラー。
- 配列リテラルは**型注釈の文脈でのみ**使用可 (`let` の型注釈・fn 引数・`ret`)。
  例外 (v2.1 明確化): `copy` の片方の引数が配列リテラルのとき、もう片方の
  確定配列型を期待型として補完する (両方リテラルは型が決まらず型エラー)。
- 添字は `a[i]`。`i` は i64 のみ。境界外 (i<0 または i>=N) は実行時エラー exit 3。
- 配列要素への代入: `a[i] = expr;` / `a[i] += expr;` 等 (複合代入も可)。
- str 配列は禁止。空配列リテラル `[]` は禁止 (長さ 0 の配列は存在しない)。

## 4. 文 (16 種)

```text
let x: f32 = 0.1;             # 型付き束縛 (内側スコープで shadowing 可)
x = x * 2.0;                  # 代入 (既存変数のみ・型一致必須)
const PI2: f32 = 3.14159274 * 2.0;   # トップレベル定数 (§4.1)
fn add(a:i64,b:i64)->i64 { ret a+b; }  # 関数 (トップレベルのみ)
if x > 0.5 { p "big"; } elif x > 0.2 { p "mid"; } else { p "small"; }
while cond { ... }            # 条件は bool 必須
for i: i64 in 0..10 { ... }   # range for (§4.3)
loop { ...; if cond { break; } }  # 無限ループ (§4.5)
match x { 0 => {..} 1 => {..} _ => {..} }  # match 文 (§4.6)
x += 1.0;                     # 複合代入 (§4.2)
break; / continue;            # ループ制御 (§4.4)
ret expr;                     # 関数内のみ
p expr;                       # 値の出力 (全型可) 1 行 1 値
assert expr;                  # false なら exit 3。assert expr, "label"; も可
a[i] = expr;                  # 配列要素代入 (複合代入 a[i] += e; も可)
{ let y: f32 = 1.0; p y; }    # 裸ブロック (スコープ)
```

### 4.1 `const` 宣言

```text
const NAME: TYPE = EXPR;
```

- トップレベルにのみ書ける。`fn` より前でも後でも**参照可 (順序不問)**。
- `TYPE` は `f32 i64 u32 bool` のいずれか (配列・str の const は禁止)。
- `EXPR` は**定数式**: 数値/bool リテラル・他の `const` 名・同型の
  `+ - * / %`・整数の `& | ^ << >>`・単項 `- ! ~`・組込変換 `f() i() u()`・括弧。
  変数参照・比較・その他関数呼び出しは禁止。ゼロ除算はコンパイルエラー。
- コンパイル時に値が確定し、実行時コードを生成しない。
- 名前空間: `fn` 名・トップレベル `let` 名と共有 (重複は型エラー exit 2)。
  関数内の `let` は const を shadowing 可。const への代入は型エラー。

### 4.2 複合代入

```text
x += expr;   # x = x + expr; と等価
x -= expr;  x *= expr;  x /= expr;  x %= expr;
```

- 対象は既存のスカラー変数または配列要素 (`a[i] += expr;`)。
- 型規則は通常の二項演算と同一 (同型の f32/i64/u32、暗黙変換なし)。

### 4.3 `for` ループ

```text
for VAR: i64 in START..END { BODY }    # END は含まない
for VAR: i64 in START..=END { BODY }   # END を含む
```

- `VAR` の型は常に `i64` (型注釈は必須だが i64 以外は書けない)。
- `START`/`END` は `i64` 型式。**ループ開始時に 1 回だけ評価**される。
- `START >= END` (排他) / `START > END` (包含) なら本体は 0 回実行 (エラーにしない)。
- `VAR` はループ本体のスコープに束縛 (外から見えない・同名は shadowing)。
- `VAR` への代入・複合代入は**型エラー** (インデックス操作は `while` を使う)。
- ステップは必ず +1 (逆順は本体内で `N - 1 - i` 等で計算)。
- i64::MAX 到達時は防御的に打ち切る (wrapping 永久ループ回避)。

### 4.4 `break` / `continue`

- `break;` — 最も内側の `while`/`for`/`loop` を即時終了。
- `continue;` — 最も内側のループの次イテレーションへ。
- ループ外では構文エラー (exit 2)。ラベル付き・値渡しの構文は存在しない。

### 4.5 `loop` ブロック

- 条件なし無限ループ。脱出は `break` (または関数内なら `ret`)。
- 実行ステップ上限 (10,000,000) 超過は exit 3。

### 4.6 `match` 文

```text
match EXPR {
  PAT => { BODY }
  PAT => { BODY }
  _   => { BODY }
}
```

- `EXPR` の型は `i64` または `bool` のみ (f32 は IEEE 等値の曖昧さ回避のため禁止、u32 も禁止)。
- `PAT`: i64 なら整数リテラル・i64 の `const` 名・負リテラル (`-3`)・`_`。
  bool なら `true`/`false`/`_`。
- 複数パターンの `PAT | PAT` 腕は**禁止** (別腕に分ける)。
- 腕の値の**重複は型エラー** (const 解決後の値で判定)。
- `_` は最後の腕にのみ。i64 では `_` 腕が**必須** (網羅強制)、
  bool は `true`/`false` 両腕で `_` 無しも可。
- fall-through なし。`match` は**文** (式ではない・値を返せない)。

### 4.7 その他の既存ルール (変更なし)

- 式文 (副作用だけの関数呼出) は禁止。出力は必ず `p`。
- `fn` はトップレベルのみ・再帰可 (深度上限 2048)・構文的に 1 つ以上の `ret`。
- `elif` は `else { if ... }` への脱糖 (v2.1 追加)。
- assert は `assert cond;` または `assert cond, "label";` (ラベルは失敗時メッセージに出る)。

## 5. 式・演算子優先順位 (全て左結合・Rust と同一)

```text
1.  ||                       (bool)
2.  &&                       (bool・短絡評価)
3.  == != < <= > >=          (同型の f32/i64/u32、== != は bool も可)
4.  |                        (同型の i64/u32)   ★ v2.1
5.  ^                        (同型の i64/u32)   ★ v2.1
6.  &                        (同型の i64/u32)   ★ v2.1
7.  << >>                    (左辺 i64/u32・右辺 i64、マスク付き wrapping)  ★ v2.1
8.  + -
9.  * / %
10. 単項 - ! ~               (- は f32/i64、! は bool、~ は i64/u32)  ★ ~
11. 呼出 f(...) / 添字 a[i] / 括弧 / リテラル / 変数 / const 名
```

- f32 比較は IEEE 意味論そのもの: NaN が絡むと `< <= > >= ==` は全て false、`!=` は true。
- i64/u32 の四則は wrapping、`/` `%` はゼロ除算で exit 3。
- シフト量は**マスク付き wrapping** 固定 (i64 は &63、u32 は &31。`1 << 65` は `1 << 1` = 2)。
- f32 の `%` は Rust の `%` (fmod 意味)。
- 添字は右辺値として使える。代入左辺は文の構文 (§4.2)。多次元添字は禁止。

## 6. 組み込み関数 (全て静的型付き)

### f32 数学 (libm FFI、ctypes libm と bit 同一検証済)

| 関数 | 型 | 備考 |
|------|-----|------|
| `sqrt(x)` | f32→f32 | libm sqrtf (正確丸め) |
| `exp(x)` | f32→f32 | libm expf |
| `ln(x)` | f32→f32 | libm logf |
| `pow(x,y)` | f32×f32→f32 | libm powf |
| `sin(x)` `cos(x)` `tan(x)` | f32→f32 | libm sinf/cosf/tanf (tan は v2.1) |
| `atan2(y,x)` | f32×f32→f32 | libm atan2f |
| `hypot(x,y)` | f32×f32→f32 | libm hypotf (v2.1) |
| `fma(a,b,c)` | f32×f32×f32→f32 | **単一丸め** a*b+c (v2.1)。`a*b+c` 二重丸めと別値になりうる (selftest ピンで実証) |
| `abs(x)` | f32→f32 | 厳密 (符号ビット) |
| `floor(x)` `ceil(x)` `trunc(x)` | f32→f32 | 厳密 |
| `round(x)` | f32→f32 | 最近接・同着は零から遠い方 |
| `min(x,y)` `max(x,y)` | f32×f32→f32 | 片方 NaN なら他方、両方 NaN なら NaN |
| `copysign(x,y)` | f32×f32→f32 | 厳密 |

### ビット・判定・定数

| 関数 | 型 | 備考 |
|------|-----|------|
| `bits(x)` | f32→u32 | to_bits |
| `b(h)` | u32→f32 | from_bits |
| `is_nan(x)` `is_inf(x)` `is_fin(x)` | f32→bool | |
| `nan()` `inf()` `ninf()` | ()→f32 | NaN は正カノニカル 0x7FC00000 |
| `pi()` `e()` | ()→f32 | π=0x40490FDB・e=0x402DF854 (wave 116 の固定点) |

### 明示変換

| 関数 | 型 | 備考 |
|------|-----|------|
| `f(x)` | i64→f32 / u32→f32 | 最近接偶数丸め (Rust `as`) |
| `i(x)` | f32→i64 / u32→i64 | f32 は飽和、u32 は拡大 |
| `u(x)` | f32→u32 / i64→u32 | f32 は飽和、i64 は下端切捨て |

### 配列組み込み関数

| 関数 | 型 | 備考 |
|------|-----|------|
| `len(a)` | [T;N]→i64 | 配列の長さ N |
| `fill(a, v)` | ([T;N], T)→[T;N] | 全要素を v で埋めた新配列 (元は不変) |
| `copy(dst, src)` | ([T;N],[T;N])→[T;N] | src の複製を返す (dst は型・長さ整合の指定)。N 不一致は型エラー |

```rq
let a: [f32; 4] = [1.0, 2.0, 3.0, 4.0];
let b: [f32; 4] = fill(a, 0.0);
p len(a);     # 4
a[2] = 99.0;
p a[2];       # 99
```

## 7. --prelude (標準小関数群・v2 で 9 行)

```text
fn dot3(ax:f32,ay:f32,az:f32,bx:f32,by:f32,bz:f32)->f32 { ret ax*bx+ay*by+az*bz; }
fn len3(x:f32,y:f32,z:f32)->f32 { ret sqrt(dot3(x,y,z,x,y,z)); }
fn ns(x:f32,y:f32,z:f32)->f32 { let l:f32 = len3(x,y,z); if l > 1e-8 { ret 1.0/l; } ret 1.0; }
fn luma601(r:f32,g:f32,b:f32)->f32 { ret 0.299*r+0.587*g+0.114*b; }
fn luma709(r:f32,g:f32,b:f32)->f32 { ret 0.2126*r+0.7152*g+0.0722*b; }
fn clamp01(x:f32)->f32 { if x < 0.0 { ret 0.0; } if x > 1.0 { ret 1.0; } ret x; }
fn lerp(a:f32,b:f32,t:f32)->f32 { ret a+(b-a)*t; }
fn sign(x:f32)->f32 { if x > 0.0 { ret 1.0; } if x < 0.0 { ret -1.0; } ret 0.0; }
fn frac(x:f32)->f32 { ret x-floor(x); }
```

| 関数 | bit 同一の対象 | 備考 |
|------|---------------|------|
| `dot3`/`len3` | opt-gfx `Vec3::dot`/`length` | 左結合 + sqrtf |
| `ns` | `Vec3::normalize` の逆数係数 | l<=1e-8 で 1.0 (v*ns は normalize と bit 同一) |
| `luma601`/`luma709` | codebase の luma | 左結合で bit 同一 |
| `clamp01` | GLSL `clamp(x,0,1)` 同形 | **NaN は全比較 false でそのまま透過** (実装通り) |
| `lerp` | `a+(b-a)*t` 形 (GLSL mix 代表実装と同形) | |
| `sign` | GLSL `sign` 同形 | NaN→0.0、±0→0.0 |
| `frac` | HLSL `frac`/GLSL `fract` 同形 | `x - floor(x)` |

## 8. 出力形式 (p)

```text
f32   : 0x3F800000 1          # 0x + bits 8 桁 16 進大文字 + 空白 + 最短往復 10 進
u32   : 0x3F800000 1065353216
i64   : 0x0000000000003039 12345
bool  : true / false
str   : 内容そのまま
[T;N] : [ v0, v1, v2 ]        # 各要素をスカラーと完全同一の形式で , 区切り・[ ] 囲み
特殊  : NaN / inf / -inf / -0
```

- 配列の要素はスカラー規則そのまま (`1.0` ではなく `1` と出る点に注意:
  最短往復 10 進がここでも一貫適用される)。
- 裸の配列リテラル `p [1.0, 2.0];` は型注釈が無いため型エラー。
  注釈済み変数 (`p a;`) または `fill/copy` の結果を渡す。

## 9. スコープ規則

1. トップレベルには v1 同様に全ての文を書ける (`let`/制御文/`p` 等)。
   `const` と `fn` のみ順序不問でホイスティング解決される。
   (注: v2 草案§9-1 の「トップレベルに let 禁止」は v1 との後方互換を壊す
   誤記のため採用しない — errata として本節に明記。)
2. 各ブロック `{ }` はスコープを形成。抜けると内側の `let` は消滅。
3. shadowing: 内側で同名 `let` を再定義可 (型が違っても良い。Rust 同様)。
4. `for` のループ変数はループブロックのスコープ (不変・§4.3)。
5. 関数パラメータは関数スコープ (shadowing 可)。
6. `const` 名は全スコープから参照可 (グローバル)。

## 10. 関数・配列の構文例

```rq
fn clamp(x: f32, lo: f32, hi: f32) -> f32 {
  if x < lo { ret lo; }
  if x > hi { ret hi; }
  ret x;
}
fn dot_arr(a: [f32; 3], b: [f32; 3]) -> f32 {
  ret a[0]*b[0] + a[1]*b[1] + a[2]*b[2];
}
fn scale_arr(a: [f32; 3], s: f32) -> [f32; 3] {
  let r: [f32; 3] = a;
  r[0] = a[0]*s; r[1] = a[1]*s; r[2] = a[2]*s;
  ret r;
}
```

## 11. Python からの移行対応表 (v2)

| 旧 Python (struct+ctypes/numpy) | rq v2 |
|---|---|
| `struct.pack('<f', x)` で逐次丸め | 不要 (全演算が最初から f32) |
| `ctypes.CDLL("libm.so.6").expf` | `exp(x)` (同じ libm FFI) |
| `'0x%08X' % bits(x)` | `p x;` |
| FNV/ビットパックの手計算 | `& \| ^ ~ << >>` (§5) |
| `for i in range(N):` | `for i: i64 in 0..N { }` |
| `while True: ...; break` | `loop { ...; break; }` |
| `np.zeros(N)` での初期化 | `let a: [f32; N] = fill(a, 0.0);` |
| `a[:] = b[:]` | `a = copy(a, b);` |
| `math.pi` 系定数の埋め込み | `pi()` (0x40490FDB 保証) / `const` |
| `x = np.clip(x, 0, 1)` | `x = clamp01(x)` (--prelude) |
| `math.fma` (3.13) | `fma(a, b, c)` (単一丸め) |

## 12. 実用例 v2 (行列積・for 分類)

```sh
rspeed rq --prelude -e '
fn mv3(m0:f32,m1:f32,m2:f32,m3:f32,m4:f32,m5:f32,
       m6:f32,m7:f32,m8:f32,v:[f32;3])->[f32;3] {
  let r:[f32;3] = [0.0,0.0,0.0];
  r[0] = m0*v[0]+m1*v[1]+m2*v[2];
  r[1] = m3*v[0]+m4*v[1]+m5*v[2];
  r[2] = m6*v[0]+m7*v[1]+m8*v[2];
  ret r;
}
let col: [f32; 3] = [0.8, 0.2, 0.1];
let out: [f32; 3] = mv3(
   3.2404542, -1.5371385, -0.4985314,
  -0.9692660,  1.8760108,  0.0415560,
   0.0556434, -0.2040259,  1.0572252,
  col);
for ch: i64 in 0..3 {
  p bits(out[ch]);
}
'
```

## 13. 設計の非目標 (明示的に持たないもの)

構造体・タプル・f64 型・文字列演算・import・メモリ確保・副作用 (時刻/乱数/
ファイル)・多次元配列・ジェネリクス・クロージャ・イテレータ・演算子
オーバーロード・break への値渡し・match 式 (文のみ)・ラベル付き break・
参照/ポインタ。

f64 は「f32 監査特化で型系を単純に保つ」ために見送る。必要になれば
型名・組込シグネ確定の上で最小追加する。構文の一次情報は常に本書
(追加のたびに本書を更新する規約)。
