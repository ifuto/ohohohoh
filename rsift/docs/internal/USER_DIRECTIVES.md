## 7. 未配線・スタブ・TODO 残しの全面禁止 (2026-07-26 追加)

- 原文: 「ちなみに、スタブ、ToDo残し、消費者なし、実装はしたものの未配線
  などは一切禁止です。」
- 解釈規則 (§3.3「スタブや見送り無し」の強化版として受理):
  1. **スタブ・no-op・仮実装は存在自体が禁止** (AUDIT_STUB_WIRING 系の残存を
     許容しない)。
  2. **TODO・「引継ぎ」「棚卸し」名目の未消化も禁止** — wave 内で検出した
     課題はその wave (または直後の連続工程) で実装まで行き、文書上の
     先送りに留めない。
  3. **消費者なしの実装は禁止** — §4 (directive⑦) の「消費者追加を先に
     検討する」を**必須化**する: 消費者ゼロの機構は、実消費者を追加
     配線して意味のある出力に接続するか、それが不可能と証明できる場合に
     限り削除する。文書注記だけで存置しない。
  4. **実装済みだが未配線の機構は禁止** — 配線 (wiring) までが実装。
- 本指示と directive⑦ の統合: 「有用なら消すな」は維持するが、有用性の
  証明責任はエージェント側にあり、**配線による実用化が第一選択**。
  「消費者ゼロのまま保持」は新指令下では違反状態。
- 適用開始: wave 135 から。直近の自分の引継ぎ項目 (wave 134 EH-5 の
  O(L×N) 範囲制限化、EH-1 の座標正規化実配線) を最初の消化対象とする。
