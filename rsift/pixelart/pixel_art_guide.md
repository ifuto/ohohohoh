# RSift ピクセルアート・ベストプラクティス ガイド

`mc_sprite_sheet.png` の全17ページ + 絵画47点は、このガイドの作法で機械生成されています。
再現は3本のスクリプトのみ（依存: `Pillow` / `numpy`）。

```bash
python3 gen_sprites.py        # sprites/*.png  (17ページ, 256x256, 16px原寸)
python3 generate_paintings.py # paintings/*.png (47点 + paintings_atlas.png)
python3 gen_sheet.py          # mc_sprite_sheet.png (全ページ縦結合 1152x10116)
```

## 1. 鉄則（MCベストプラクティス = "書き割り"）

| # | 規則 | 理由 |
|---|---|---|
| 1 | **16px ネイティブグリッド** — 1ピクセル = テクスチャの1ドット。拡大は NEAREST のみ | AA・バイリニアで滲んだ時点でMCの質感が死ぬ |
| 2 | **斜め/曲線は階段に分解** — 45°以外は 2:1 / 1:2 階段パターン | 「汚い斜線」はドット絵の最大の敵 |
| 3 | **色数は1タイル ≤ 5色** (shade 込み) | 塗り分けパレットがMCの世界観の根幹 |
| 4 | **輪郭は 1px の暗色** (完全な黒は禁止、色の影色を使う) | 黒ベタだと夜間に埋もれて認識不能になる |
| 5 | **ライトは左上固定** — ハイライト左上 / 影右下 | バニラ全テクスチャの光源一貫性 |
| 6 | **面の質感は小スプライトでは「2色ノイズ」まで** — ディザは目立たない密度で | 過剰なノイズ = 遠目で霞む |

## 2. 絵画（paintings）専用の4技法

`generate_paintings.py` の `Cnv` クラスに実装済み:

| 技法 | 実装 | 効果 |
|---|---|---|
| **stipple** | ハッシュ決定論スプレー (密度 0–255) | 霧・粒子・葉擦れ・夜の星。乱数に見えて完全再現 |
| **gridretch** | 縦/横の交互2色帯 (grid + stretch) | 水面・カーテン・板の張り合わせ。1pxずらし感を量なしで出す |
| **filtlumi** | 16pxセル単位で輝度を平均±14にクランプ | いわゆる filtlumi。セル内の輝度暴発を防ぎアトラスを均質に保つ |
| **threedci** | 各筆（stroke/blob）の深さプッシュ/プル | 平面的な書き割りに擬似3Dの奥行き。`rays`/`blob` の層適用で実現 |

## 5. 検証（常に実行）

`gen_sheet.py` / `gen_sprites.py` 実行後:

```python
from PIL import Image
import numpy as np
a = np.array(Image.open("mc_sprite_sheet.png").convert("RGB"))
print(a.shape, np.unique(a.reshape(-1,3), axis=0).shape)  # 色爆発していないか
```

- スプライト: 各タイルの使用色 ≤ 16色、透明ピクセルは装飾タイルのみ
- 絵画: filtlumi 適用後の輝度クリップ率が正常範囲 (≈0–12%)
- シート: 10116px 高、17ページ + 絵画アトラス帯
